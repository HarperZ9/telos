# telos-workbench

Use when the user asks to inspect the local Telos workbench, available capabilities, or evidence receipts. Start with telos.status and telos.catalog. Missing sibling tools remain unavailable; installing this plugin does not install or authorize them. Status and manifests are descriptions, not proof that an action ran. Do not call native control, network, rendering, execution, or file-writing tools without matching user intent and scoped permission. Keep private payloads local unless the user authorizes transmission. Report receipt verdicts with their limits. The client supplies the model; this plugin supplies local tools.
